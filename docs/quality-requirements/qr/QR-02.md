# QR-02: Check The Coach's Spoken Decisions From A Clean Checkout

A developer can run the checks that cover the coach's spoken decisions from a clean checkout, and a change that breaks one of those decisions fails them.

- **Status:** Active
- **Characteristic:** Maintainability
- **Sub-characteristic:** Testability
- **Business importance:** High
- **Technical risk:** Medium

## Scenario

### Source

A developer who has just cloned the repository changes the coach's spoken decisions.

### Stimulus

The developer edits the session logic in `app/src/main/java/app/runningcoach/SessionEngine.kt`, the module that decides which lines are spoken and when, and runs the checks.

### Environment

A clean checkout on a machine set up from `docs/setup.md`, with no phone and no emulator attached, so the checks run without a device.

### Artifact

The session logic in `app/src/main/java/app/runningcoach/SessionEngine.kt`, exercised by `app/src/test/java/app/runningcoach/SessionEngineTest.kt`; the Android entry points `app/src/main/java/app/runningcoach/MainActivity.kt` and `app/src/main/java/app/runningcoach/CoachService.kt` stay outside the unit checks because they need a device.

### Response

The checks shall run to a pass or a fail on the developer's machine without a device, and shall fail when a spoken decision changes.

### Response Measure

`gradle :app:testDebugUnitTest` completes without a device from a clean checkout, and a change that alters which line the session logic speaks, or when it speaks it, fails at least one test.
