# FR-013: Record Each Step Of The Core Task

- **Status:** Active
- **Traces to:** [`US-12`](https://github.com/Running-Coach-App/running-coach-app/issues/167), [`ADR-001`](../../architecture/adr/ADR-001.md)
- **Containers:** `coach app`

## Behavior

The product shall record an event for each step of the core task: a session starting, the coach producing a stats line or an effort cue, a question being asked and answered, a location fix being lost and regained, a session stopping, and the after-run summary being spoken.

Each event shall carry the session it belongs to, the moment it happened, and what the traffic is, together with the fields [`docs/analytics.md`](../../analytics.md#the-events) gives it.

The session identifier shall be generated at random when the session starts. It shall not be derived from anything about the runner and shall not be reversible to them, and each session shall get its own.

No event shall carry a name, an email address, a phone number, an address, free text, or anything the runner said. A question shall record which stat it was about, and whether it was answered, and nothing else.

The product shall write the events to a file in its own private storage, one event per line, and shall send them nowhere. A runner exports that file when they choose to.

The product shall keep the most recent events and drop the oldest, so the file cannot grow without end.

Recording shall never stop a session: a failure to write an event shall leave the coach running.

## Acceptance Criteria

### AC-01

Given a session that starts, speaks a stats line, answers a question, and stops, when its events are read back, then each of those steps appears once, in the order it happened.

### AC-02

Given two sessions on the same phone, when their events are read back, then each carries its own session identifier and the two differ.

### AC-03

Given a spoken question about pace, when the question's events are read back, then they record the topic and whether it was answered, and carry none of the words the runner used.

### AC-04

Given a phone with no network connection, when a whole session runs, then every event is still recorded, because none of them is sent anywhere.

### AC-05

Given a file that cannot be written to, when a session runs, then the coach speaks the session through to its stop regardless.
