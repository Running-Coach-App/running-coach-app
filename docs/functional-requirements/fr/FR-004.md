# FR-004: Answer A Spoken Question About The Current Run

- **Status:** Active
- **Traces to:** [`US-04`](https://github.com/Running-Coach-App/running-coach-app/issues/40), [`DEC-008`](../../decisions.md#dec-008), [`DEC-016`](../../decisions.md#dec-016), [`ADR-001`](../../architecture/adr/ADR-001.md), [`ADR-004`](../../architecture/adr/ADR-004.md)
- **Containers:** `coach app`

## Behavior

While a session is running, when the runner asks aloud about the elapsed time, the pace, or the distance of that session, the product shall speak the stats the question asked for.

The product shall accept more than one wording of the same question, and shall not require the runner to learn a fixed list of commands.

When a question asks for more than one stat, the product shall speak each stat the question asked for.

When no session is running, the product shall say that there is no session rather than answering with a stat.

## Acceptance Criteria

### AC-01

Given a session running for twelve minutes, when the runner asks how long they have been running, then the coach speaks the elapsed time of that session.

### AC-02

Given a session with a location fix, when the runner asks how far they have gone, then the coach speaks the distance.

### AC-03

Given a session, when the runner asks for the time and the pace in one question, then the coach speaks both.

### AC-04

Given no session is running, when the runner asks how long they have been running, then the coach says there is no session and speaks no stat.
