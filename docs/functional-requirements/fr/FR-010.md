# FR-010: Show On Screen What The Coach Says

- **Status:** Active
- **Traces to:** [`DEC-018`](../../decisions.md#dec-018), [`DEC-022`](../../decisions.md#dec-022)
- **Containers:** `coach app`

## Behavior

When the coach speaks a line, the product shall show that line on the run screen.

The screen shall keep the previous spoken line as well, so a question and its answer can appear together.

When the runner asks a question, the product shall show that they asked it, and then show the spoken answer.

## Acceptance Criteria

### AC-01

Given a session has started, when the coach says "Session started.", then that sentence is visible on the run screen.

### AC-02

Given a session is running, when the runner asks how long they have been running, then the screen shows the question and the spoken time answer.

### AC-03

Given a session is stopped, when the coach speaks the stop line and the summary, then both remain visible with the final stats.
