# FR-003: Speak An Effort Cue When The Effort Changes

- **Status:** Active
- **Traces to:** [`US-03`](https://github.com/Running-Coach-App/running-coach-app/issues/39), [`DEC-014`](../../decisions.md#dec-014), [`ADR-001`](../../architecture/adr/ADR-001.md), [`ADR-002`](../../architecture/adr/ADR-002.md)
- **Containers:** `coach app`

## Behavior

While an interval session is running, the product shall speak the effort to hold whenever that effort changes.

The product shall not repeat an effort cue while the effort is unchanged.

While a steady session is running, the product shall speak no effort cue, and shall keep speaking the stats lines.

## Acceptance Criteria

### AC-01

Given an interval session, when the effort block changes from jog to hard, then the coach speaks the new effort once.

### AC-02

Given an interval session inside one effort block, when a minute passes without the block changing, then the coach speaks no further effort cue for that block.

### AC-03

Given a steady session that has been running for nine minutes, when the session is replayed, then the coach has spoken no effort cue and has spoken its stats lines.
