# FR-012: Let The Runner Set How Often The Stats Are Spoken

- **Status:** Active
- **Traces to:** [`US-11`](https://github.com/Running-Coach-App/running-coach-app/issues/142), [`ADR-002`](../../architecture/adr/ADR-002.md)
- **Containers:** `coach app`

## Behavior

The product shall let the runner set, before a session starts, how often the stats line is spoken during that session.

The product shall speak the stats at the interval the runner set, and shall keep that interval for later sessions until it is changed.

When the runner has set no interval, the product shall speak the stats every three minutes, which is the cadence `DEC-013` fixed.

The product shall not offer an interval so short that one stats line is still being spoken when the next falls due.

## Acceptance Criteria

### AC-01

Given a runner who has set the interval to a value the product offers, when a session runs past that interval, then the coach speaks the stats at that interval rather than every three minutes.

### AC-02

Given a runner who has never set an interval, when a session runs past three minutes, then the coach speaks the stats on the three-minute cadence.

### AC-03

Given an interval set in an earlier session, when the app is closed and opened again, then a new session uses that interval.
